# Первый полёт на Geoscan Pioneer Base

Работа посвящена подготовке к первому полёту и освоению двух способов управления:

1. Выполнение Lua-программы на полётном контроллере с возможностью перехвата управления пультом РУ.
2. Управление с ПК \ Android по Wi-Fi через модуль ESP32 с CV-камерой и библиотеку `pioneer_sdk`.


## Файлы работы

| Файл | Назначение |
| --- | --- |
| [radio/square_autopilot.lua](radio/square_autopilot.lua) | Lua-программа облёта квадрата 50 × 50 см с посадкой |
| [esp32/esp32_pc_control.py](esp32/esp32_pc_control.py) | Управление с клавиатуры ПК и просмотр видео ESP32 |
| [esp32/led_by_hight.py](esp32/led_by_hight.py) | Изменение цвета светодиодов по показаниям датчика расстояния |
| [params/Base_python-jump_OPT_10345.properties](params/Base_python-jump_OPT_10345.properties) | Конфигурация для Python / Jump  |
| [params/Base_radio_OPT_10345.properties](params/Base_radio_OPT_10345.properties) | Конфигурация для радиоуправления |

## Оборудование и подготовка

Используются Pioneer Base, плата подключения дополнительных модулей с OPT, пульт РУ, аккумулятор, USB-кабель и ПК с Pioneer Station. Для второго способа нужен модуль ESP32 с CV-камерой и Python. Конфигурация для нужного варианта полета должна быть загружена на полетный контроллер. 

## Способ 1. Lua-программа на автопилоте и пульт РУ

Программа загружается на полётный контроллер и выполняется на нём. ПК нужен для подготовки и загрузки; выполнение маршрута не требует Python или Wi-Fi.

### Подключение и настройка пульта

Для управления с пульта загрузить в автопилот [конфигурацию радиоуправления с OPT](params/Base_radio_OPT_10345.properties). Подключение и настройку FlySky FS-i6S выполнить по документации Геоскана:

1. [Настройка пульта](https://docs.geoscan.ru/pioneer/instructions/remote-controller/fsi6s/rc_setting.html) — параметры передатчика, назначение каналов и тумблеров. Для совместимого приёмника FlySky выбрать протокол `PPM` в меню `OUTPUT MODE → Output → PPM`.
2. [Связь пульта с приёмником](https://docs-beta.geoscan.ru/pioneer/instructions/remote-controller/fsi6s/rc_connection.html) — подключение приёмника к автопилоту и процедура привязки `BIND`.

После привязки проверить реакцию дрона на стики и переключение режимов. Если используется другая модель пульта, выбрать соответствующую инструкцию в разделе [«Пульт радиоуправления»](https://docs-beta.geoscan.ru/pioneer/instructions/remote-controller/remote-controller.html).

### Полётное задание

В [square_autopilot.lua](radio/square_autopilot.lua) задан следующий маршрут; координаты указаны в метрах относительно точки старта:

| Точка | X | Y | Z |
| --- | --- | --- | --- |
| 1 | 0.0 | 0.5 | 0.5 |
| 2 | 0.5 | 0.5 | 0.5 |
| 3 | 0.5 | 0.0 | 0.5 |
| 4 | 0.0 | 0.0 | 0.5 |

Замысел программы: подготовка к полёту через 2 секунды после запуска, команда взлёта через 6 секунд, затем обход четырёх точек и посадка. После события `TAKEOFF_COMPLETE` задаётся первая точка; каждое событие `POINT_REACHED` переводит дрон к следующей. После последней точки отправляется `Ev.MCE_LANDING`.

### Порядок запуска

1. Подключить дрон к Pioneer Station и проверить выбор OPT.
2. Загрузить Lua-файл в полётный контроллер.
3. Включить настроенный пульт и перевести `SWB` в нижнее положение — выполнение задания.
4. Установить дрон на площадку и запустить скрипт физической кнопкой «Старт» на автопилоте. Учесть, что программа сама отправляет команды подготовки и взлёта по таймерам.
5. Наблюдать за маршрутом и посадкой; при необходимости перехватить управление пультом.


### Режимы пульта и перехват

В инструкции производителя для этой конфигурации указаны следующие положения `SWB`:

| Положение | Режим |
| --- | --- |
| Нижнее | Выполнение миссии / скрипта |
| Среднее | Ручной полёт |
| Верхнее | Ручное управление в режиме Stabilize |

Для перехвата переводят `SWB` из режима задания в ручной режим. 

## Способ 2. Управление с ПК через ESP32

Python-программа выполняется на компьютере. Команды передаются по Wi-Fi модулю ESP32, который связан с автопилотом по UART. Скрипт [esp32_pc_control.py](esp32/esp32_pc_control.py) имитирует каналы пульта и запускает окно видеопотока через `VideoStream`.

### Подготовка Python и подключение

```powershell
python -m venv .venv
.\.venv\Scripts\python.exe -m pip install pioneer-sdk==0.6.1 keyboard==0.13.5
```

Сведения о библиотеке: [репозиторий Pioneer SDK](https://gitflic.ru/project/geoscan-llc/pioneer-sdk), [справочник класса Pioneer](https://docs.geoscan.ru/pioneer/programming/pio-sdk/pioneer/). Скрипты используют пакет `pioneer_sdk` первой версии; при установке `pioneer_sdk2` потребуется адаптация кода.

1. Подготовить прошивку и параметры для установленного ESP32, подключить модуль и подать питание.
2. Подключить ПК к Wi-Fi сети дрона вида `Pioneer…` и пароль `12345678`.
3. Запустить программу.



### Светодиодная индикация высоты

Отдельный скрипт [led_by_hight.py](esp32/led_by_hight.py) считывает `get_dist_sensor_data()` примерно раз в `0.1` с и меняет цвет всех светодиодов (`led_id=255`, яркость активных компонентов RGB — `0.1`):

| Показание датчика | Цвет |
| --- | --- |
| До 0,25 м включительно | Красный |
| Более 0,25 м, до 0,50 м включительно | Зелёный |
| Более 0,50 м, до 0,75 м включительно | Синий |
| Более 0,75 м | Белый |

Этот скрипт не отправляет полётных команд. При `Ctrl+C` он выключает светодиоды и закрывает соединение.
