# Полёт по квадрату: Геоскан Пионер Base + OpenMV

Следующий шаг после [полёта по линии](../1_line_detect/README.md): лента выложена квадратом. Камера не только находит линию и её смещение от центра кадра,
но и замечает углы квадрата и сама меняет направление движения. Автопилот получает направление и смещение и показывает их светодиодами.
Моторы пока не используются.

Запись проверки на столе — [`test.mp4`](./test.mp4).

### Протокол обмена

Камера раз в 100 мс отправляет один байт:

| Байт | Значение |
|---|---|
| `0` | линия не найдена |
| `1..124` | `1 + dir × 31 + (q + 15)` |

- `dir` — текущее направление: `0` вперёд, `1` вправо, `2` назад, `3` влево;
- `q` — смещение линии вбок от курса в единицах по 3 пикселя
  (`CROSS_UNIT`), обрезано до −15…+15, т. е. примерно −45…+45 пикселей.

Расшифровка на дроне: `v = байт − 1`, `dir = v // 31`, `cross = (v − dir × 31 − 15) × 3`.
Поворот дрон определяет сам — по смене `dir` между соседними байтами.

### Поиск линии на камере

1. Снимок 160×120.
   Если камера стоит «вверх ногами», кадр разворачивается на 180° (`FLIP_180`).
2. Для белой ленты из каждого пикселя берётся минимум из R, G, B — «насколько
   пиксель белый». Коричневый стол почти без синего становится тёмным, и лента
   выделяется сильнее, чем по обычной яркости. Для чёрной ленты — максимум.
3. Кадр режется на 6 горизонтальных и 8 вертикальных полос по 20 пикселей.
   Для каждой полосы строится профиль яркости.
4. В профиле ищутся «гребни» — участки, которые ярче фона с обеих сторон хотя бы
   на `MIN_CONTRAST`. Слишком узкие (`MIN_LINE_W`) и слишком широкие (`MAX_LINE_W`)
   отбрасываются, как и куски слабее `REL_STRENGTH` от самого контрастного в кадре
   (текстура стола, блики).
5. Куски из соседних полос собираются в цепочки: соседний кусок должен быть рядом
   (`MAX_JUMP`) и похожей толщины. Выбирается длинная и ровная цепочка, которая
   ближе всего к линии, по которой летели раньше (`TRACK_K`), — поэтому дрон
   не перескакивает на параллельную сторону квадрата.
6. Основная линия — цепочка вдоль курса. По ней прямой считается смещение
   `cross` в точке напротив центра кадра.

### Поворот на углу

Поперечная линия — цепочка поперёк курса. Она засчитывается как угол, только если:

- в ней не меньше `MIN_CHAIN_PERP` кусков (пятно сбоку — 1–2 куска);
- она впереди и уже подошла к центру кадра ближе `TURN_PX`
  (или `TURN_FAR`, если основная линия у самого угла уже пропала);
- она уходит в одну сторону минимум на `SIDE_MIN` пикселей,
  а в другую — только короткий хвост;
- она начинается у основной линии (угол связан, а не отдельный предмет).

После поворота `TURN_COOLDOWN` кадров новые повороты не делаются, а для новой
линии хватает более короткой цепочки (`MIN_CHAIN_AFTER_TURN`). Если линии по курсу
нет `REACQUIRE` кадров, а через центр кадра идёт лента поперёк, — направление
считается сбитым, и камера переходит на эту ленту.


### Светодиоды на дроне

| Светодиод | Значение |
|---|---|
| `LED_SHIFT_LEFT` / `LED_SHIFT_RIGHT` белый | лента левее / правее курса — сдвинуться туда |
| `LED_TURN_LEFT` / `LED_TURN_RIGHT` жёлтый | камера повернула налево / направо (1,5 с) |
| все не горят | лента под дроном |
| крайние красные | ленты не видно |

## Как настроить

| Параметр | Где | Что менять |
|---|---|---|
| `LINE_COLOR` | камера | `"white"` — светлая лента на тёмном столе, `"black"` — тёмная линия |
| `MIN_CONTRAST` | камера | ловится стол/блики → увеличить; лента теряется → уменьшить |
| `REL_STRENGTH` | камера | ловится текстура/блики → увеличить; лента теряется → уменьшить |
| `MAX_LINE_W` | камера | лента на снимке толстая (низко летим, широкая разметка) → увеличить |
| `START_DIR` | камера | с какого направления начинаем: 0 вверх, 1 вправо, 2 вниз, 3 влево |
| `TURN_PX`, `TURN_FAR` | камера | поворот срабатывает поздно → увеличить, рано → уменьшить |
| `SIDE_MIN` | камера | ложные повороты на пятна сбоку → увеличить |
| `TURN_COOLDOWN` | камера | двойные повороты на одном углу → увеличить |
| `FLIP_180` | камера | нос дрона внизу кадра → `True` |
| `DRAW_ALL` | камера | `True` — рисовать все найденные куски (отладка) |
| `ON_PX`, `OFF_PX` | дрон | ширина «нормы» вокруг центра |
| `TURN_TICKS` | дрон | сколько тактов (по 0,1 с) показывать поворот |
| `SILENCE` | дрон | тактов без данных от камеры до «ленты нет» |
