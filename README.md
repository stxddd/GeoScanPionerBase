# Геоскан Пионер

Материалы и инструкции по настройке и прошивке БПЛА «Геоскан Пионер».

Цель проекта - научить квадрокоптер «Геоскан Пионер Base» лететь вдоль линии под собой, используя камеру OpenMV на плате расширения.

- [2_sqare_detect — полёт по квадрату, повороты на углах, LED индикация](./2_sqare_detect/README.md)
